## 🚀 Cara Menjalankan Program

1. Clone repository ini.
2. Buka project menggunakan **Apache NetBeans** atau IDE Java lainnya.
3. Pastikan JDK telah terinstal.
4. Jalankan file utama (Main Class).
5. Login menggunakan salah satu akun yang tersedia di atas.
